# Evergreen Home Watch Website

Static one-page HTML/CSS/JS site for a local Evergreen-area home watch and short-term-rental turnover business.

## Files
- `index.html` — all page content and sections
- `styles.css` — styling and responsive layout
- `script.js` — mobile navigation and current year

## Before launch
Replace all instances of:
- `EVERGREEN PROPERTY WATCH`
- `PHONE NUMBER HERE`
- `hello@evergreenpropertywatch.com`
- any placeholder owner/about text
- placeholder reviews

## One-page navigation
The navigation uses in-page anchors only. It does not send visitors to separate pages.

## Free hosting
This site can be hosted as a static site on Cloudflare Pages connected to a GitHub repository. No build command is required.
